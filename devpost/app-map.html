sofer — app map

A compact guide to the sofer codebase, written so you can read it in 3–5 minutes and reuse one practice the next time you start a project with an agent.

What sofer does

sofer teaches Modern Standard Arabic to English-speaking beginners through tappable tokens on real beginner sentences. The learner reads a vowelled Arabic sentence, taps any word to see its contextual meaning and a one-sentence grammar note, answers a 4-option comprehension question, and tracks progress in browser localStorage. An optional "Explain with AI tutor" button calls the AMD Token Factory chat-completions endpoint through a small Express proxy.

The kernel (where to start reading)

The whole product hangs on one interaction: tap a token → see a real explanation. Everything else is supporting structure for that interaction.

The kernel in 4 code locations

To trace the kernel in the code, open these in order:

  1. client/src/content/lessons.json — one lesson with two tokens; the data the kernel renders against.
  2. client/src/pages/LessonPlayer.tsx — the page that wires SentenceArea, TokenPanel, and QuestionArea together.
  3. client/src/components/SentenceArea.tsx — renders the RTL Arabic line with one button per token, handles arrow-key focus stepping.
  4. client/src/components/TokenPanel.tsx — opens on tap; shows the curated meaning, grammar note, Listen, Mark tricky, and an AI tutor button.

One practice to reuse next time

Author the data before the type definitions. When you sit down to build something where the content has internal structure (lessons with tokens, recipes with steps, items with properties), author two or three real examples of the content first, then write the schema that describes what you actually wrote. Trying to write the schema first leads to schemas that don't match the real shape of the data; writing the data first lets the schema catch the genuine invariants. sofer's client/src/content/lessons.json was authored by hand with deliberate Arabic diacritics, then scripts/validate-lessons.ts grew up around the invariants the data needed (offsets match substring, unique IDs, 4 options per question, exactly 7 sentences).

How to demo it

  1. npm install && npm --prefix client install && npm --prefix server install
  2. npm run dev — opens http://127.0.0.1:5173
  3. Click Start Learning → pick any lesson → tap a token → see the curated explanation
  4. Press Tab to step through tokens by keyboard, Esc to close the panel
  5. Answer the question → see the curated explanation → next sentence
  6. Open Progress → confirm 1 lesson, 1 question, accuracy
  7. Reload the tab → progress is still there
