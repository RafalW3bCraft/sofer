# Three-minute demo script draft

This script intentionally does not claim live inference until the required Firebase checks are recorded.

- **0:00–0:20:** Explain the beginner Arabic learning goal and guest-first design.
- **0:20–0:50:** Browse the 3 reviewed lessons and show the 9 clearly marked draft lessons. Open a trusted lesson, use RTL tokens, and answer its curated comprehension check.
- **0:50–1:25:** Prepare the on-device model on supported Chrome desktop and ask a short lesson question. Show Firebase's actual `inferenceSource`; if unavailable, say so and show the real failure/fallback state.
- **1:25–1:55:** Select cloud-only tutoring and show actual Firebase cloud source after the project check succeeds. Do not substitute a mock.
- **1:55–2:25:** Show vocabulary recall, sentence reconstruction, review intervals, local progress, and the curated offline lesson path.
- **2:25–3:00:** Explain Firebase AI Logic, App Check, optional Auth, owner-scoped Firestore sync, and current evidence/limitations.
